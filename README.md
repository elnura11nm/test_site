# Ғылым департаментінің сайты

Сайт Flask арқылы қызметкерлердің аккаунттары мен жарияланған мазмұнды SQLite дерекқорында сақтайды. Бастапқы беттер мен үлгілер HTML файлдарынан алынады.

## Жергілікті іске қосу

Репозиторий түбірінде Python 3.10 немесе кейінгі нұсқасымен орындаңыз.

```sh
python -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/flask --app app staff-password editor
.venv/bin/waitress-serve --listen=127.0.0.1:8000 app:app
```

Сайтты `http://127.0.0.1:8000/`, ал әкімшілік панельді `http://127.0.0.1:8000/admin` мекенжайынан ашыңыз. Құпиясөз терминалда сұралады. Әр қызметкерге жеке логин ашыңыз. Сол команда қолданыстағы логиннің құпиясөзін ауыстырады. Аккаунтты жою үшін `.venv/bin/flask --app app staff-remove editor` пәрменін қолданыңыз.

Панельден өңделетін бетті таңдаңыз. Бет атауын, сипаттамасын, тақырыптарын және мәтінін өзгертуге, бөлімге жазба қосуға немесе алып тастауға, жазба сілтемесін және «МЫСАЛ» белгісін басқаруға болады. Сақтау өзгерістерді бірден жариялайды.

## Серверде орналастыру

Waitress серверін HTTPS кері проксиінің артында іске қосып, `SCIENCE_HTTPS=1` орнатыңыз. Қызметкерлерді құру пәрмендеріне де сервер пайдаланатын `SCIENCE_DATABASE` мәнін беріңіз. Бұл айнымалы тұрақты дискідегі SQLite файлының абсолютті жолын қабылдайды. Әдепкі жол — `instance/site.sqlite3`. Дерекқорды резервтік көшірмеге қосыңыз және оның қолжетімділігін сервер пайдаланушысымен шектеңіз.

GitHub Pages статикалық файлдарды ғана ұсынады. Жүйеге кіру және өзгерістерді жариялау үшін Python сервері қажет.
